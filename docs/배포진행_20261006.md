# 배포 진행 기록

- GitHub: https://github.com/ykyoo0110-code/k-culture-producer (비공개)
- 사용자 화면: Vercel 예정, 기존 포트폴리오와 별도 프로젝트
- 서버: Render 예정, backend 폴더의 Dockerfile 사용
- 데이터 및 미디어: 기존 Supabase 사용
- 관리자 설정: Render에서 SITE_CONTENT_STORAGE_PATH=settings/site-content.json 설정. 기존 k-culture-media Storage에 JSON 저장
- 최초 설정: backend/site_content.initial.json (10월 6일 현재 관리자 설정 사본)
- 서버 구성: Python 3.13, FFmpeg, 한글 PDF용 Nanum 폰트
- 확인: 웹 빌드, 음성 업로드 및 저장 검사, 설정 보존과 저장소 장애 처리 검사 통과
- 아직 외부 서버 및 사용자 화면 배포가 완료되지는 않음. 완료 뒤 실제 주소 및 검사 결과 기록

## 서버에 입력할 항목

SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, OPENAI_API_KEY, ADMIN_PASSWORD, ADMIN_SIGNING_KEY는 로컬 backend/.env와 같은 값을 Render 환경변수에 입력합니다. GitHub에는 올리지 않습니다.

FRONTEND_ORIGIN에는 실제 Vercel 주소, BACKEND_PUBLIC_URL에는 실제 Render 주소를 입력합니다.

## 사용자 화면에 입력할 항목

VITE_API_BASE_URL에는 실제 Render 주소를 입력합니다. API 키는 사용자 화면에 입력하지 않습니다.
